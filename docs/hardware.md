# Validated hardware

## Samsung 767XCL / NP767XCM-K02BR

Confirmed during troubleshooting:

- DMI product: `767XCL`
- Model string observed in kernel logs: `NP767XCM-K02BR`
- Intel Wi-Fi 6 AX200: PCI `8086:2723`
- Intel CcP ACPI device: `INT33E4:00`
- Audio PCI device check used by the installer: `0x98c8`
- Ubuntu 26.04
- Linux 7.0.0-38-generic

This does **not** imply support for every 767XCL firmware revision or every Galaxy Book model.
